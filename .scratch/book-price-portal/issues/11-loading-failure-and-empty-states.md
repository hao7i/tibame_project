# 11: 載入、失敗與空狀態

**What to build:** 設計稿明確列為「原型未涵蓋、但需要實作」的那些狀態。使用者在取價進行中看到骨架畫面，某個通路取不到價時看到該列的失敗提示，搜尋不到東西時看到空狀態而不是一片空白。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 取價進行中顯示骨架畫面，不是空白或跳動的版面
- [ ] 單一通路取價失敗時，該通路在報價表中顯示可辨識的失敗狀態
- [ ] 搜尋無結果時顯示空狀態，而非空白頁
- [ ] 取價時間戳顯示於搜尋結果頁與單書比價頁
- [ ] 上述狀態在桌機與手機版型都正確
