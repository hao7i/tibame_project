# 04: 卡片與表格兩種呈現方式

**What to build:** 使用者在搜尋結果頁切換「列表／卡片／表格」，三種呈現方式都符合設計稿；切換後的選擇在桌機與手機之間共用。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 卡片檢視為三欄網格，含封面佔位框、分類、書名、最低價與折扣標籤、追蹤切換與比價按鈕
- [ ] 表格檢視每個通路一欄，最低價以粗體與重點色標示，該通路無報價時顯示破折號
- [ ] 表頭為深色底、淺色標籤
- [ ] 呈現方式的選擇為持續狀態，桌機與手機共用
- [ ] 三種檢視都尊重目前的篩選條件與載體條件
- [ ] 手機版對應版型可用
