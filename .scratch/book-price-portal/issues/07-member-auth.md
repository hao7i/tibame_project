# 07: 會員註冊與登入

**What to build:** 使用者可以註冊帳號、登入、登出；登入後導覽列顯示登出。這張票只做身分本身，不做追蹤功能。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 可註冊新帳號、登入、登出
- [ ] 密碼以 BCrypt 雜湊儲存，資料庫中不存明文
- [ ] 以 session cookie 驗證，不使用 JWT
- [ ] 登入頁符合設計稿：桌機兩欄（左側深色說明區、右側表單）、手機為深色區塊加表單
- [ ] 導覽列依登入狀態顯示登入或登出
- [ ] 未登入呼叫會員專屬的 API 會得到未授權回應
- [ ] 會員的身分系統與 `/admin` 的管理帳號完全獨立，不共用資料表
