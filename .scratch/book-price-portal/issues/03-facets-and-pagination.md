# 03: 搜尋結果的篩選與分頁

**What to build:** 使用者在搜尋結果頁勾選通路或分類、拉動價格上限、翻頁，結果會即時改變；而且選了通路之後，每個作品的最低價只從那些通路的報價裡算。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 通路與分類兩組 facet 可多選，同組之內為 OR、跨組為 AND
- [ ] 通路篩選會連動改變最低價的計算結果
- [ ] 價格上限滑桿會過濾結果
- [ ] 已選條件以可點擊移除的 chip 呈現，與 facet 勾選狀態同步
- [ ] 清除篩選會重設所有 facet 與價格上限
- [ ] 每個 facet 選項顯示對應筆數
- [ ] 分頁可用，變更任何篩選條件時回到第一頁
- [ ] 手機版的橫向捲動 facet chip 列可用
- [ ] Web API 層測試涵蓋篩選組合，以及通路篩選對最低價的連動
