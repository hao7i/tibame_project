# 06: 進階搜尋

**What to build:** 使用者組合欄位條件與布林運算、設定價格區間與出版年、限定通路與載體，右側的查詢式預覽即時反映這些條件，按下執行搜尋後導向結果頁且條件確實生效。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 兩列固定條件列：搜尋欄位（書名／作者／出版社／譯者／ISBN／系列）加關鍵字，第二列帶 AND／OR／NOT
- [ ] 價格下限、價格上限、出版年、限定通路、載體皆可設定
- [ ] 查詢式預覽即時反映目前條件，條件全空時顯示星號
- [ ] 執行搜尋後導向結果頁，且該頁的結果符合設定的條件
- [ ] 重設會清空所有條件
- [ ] 手機版版型可用
- [ ] Web API 層測試涵蓋布林條件的組合行為
