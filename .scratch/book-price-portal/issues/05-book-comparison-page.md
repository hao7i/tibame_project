# 05: 單書比價頁

**What to build:** 使用者從搜尋結果點進一本書，看到這個作品在各通路的完整報價、目前最低價、近 90 天價格走勢，並可切換載體與排序，點擊前往該通路購買。這是整個網站的核心畫面。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 報價表列出各通路：通路色塊與名稱、載體、庫存到貨、折扣、售價、前往購買按鈕
- [ ] 最低價那一列以底色標示並帶標籤
- [ ] 載體切換（全部版本／紙本書／電子書）同時作用於報價表與最低價卡
- [ ] 排序可在「價格低→高」與「依通路」之間切換
- [ ] 近 90 天價格走勢以行內 SVG 折線呈現，含區間標示
- [ ] 未登入時，降價通知卡顯示登入提示文案；已登入時顯示目標價欄位
- [ ] 價格為示意資料的免責文字與最後更新時間存在
- [ ] 手機版版型可用
