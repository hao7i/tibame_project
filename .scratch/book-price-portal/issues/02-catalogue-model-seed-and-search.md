# 02: 書目模型、seed 資料與搜尋

**What to build:** 使用者在首頁輸入「原子習慣」按下比價，進到搜尋結果頁，看到列表檢視列出符合的作品、各作品的最低價與有貨通路——而且這些資料來自資料庫，不是前端寫死的。這是整個系統的第一發曳光彈，端到端穿過資料庫、Service、Web API 與前端兩個畫面。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 作品、版本、報價三層落地於資料庫；版本以 ISBN 為鍵，帶載體與定價
- [ ] 原型的六本書匯入為 seed 資料，紙本與電子書拆成同一作品底下的不同版本，各通路的報價掛在對應版本上
- [ ] 搜尋支援以書名、作者、出版社、ISBN 查詢
- [ ] 搜尋結果的列表檢視符合設計稿：封面佔位框、書名、作者出版、標籤列、通路價格對、右側最低價與折扣
- [ ] 最低價由報價即時算出，不是儲存的欄位
- [ ] 首頁的熱門搜尋標籤點擊後會帶入查詢並導向結果頁
- [ ] Controller 不直接注入 Repository；Entity 不離開 Service 層
- [ ] Web API 層測試涵蓋搜尋與最低價的計算
