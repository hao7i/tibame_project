# 08: 追蹤清單與目標價

**What to build:** 會員把作品加入追蹤、設定目標價，在追蹤清單看到每本書目前的最低價與距離目標價還差多少；未登入者按下追蹤會被導向登入，登入後那本書自動進入清單。

**Blocked by:** 05, 07

**Status:** ready-for-agent

- [ ] 未登入按追蹤會導向登入頁並記住待追蹤的作品，登入後自動加入並回到該作品的比價頁
- [ ] 登入後可加入與移除追蹤，導覽列的追蹤計數即時更新
- [ ] 追蹤的對象是作品，不是版本
- [ ] 追蹤項目與目標價儲存於資料庫，重新登入後仍在
- [ ] 目標價可在清單中直接編輯，狀態即時重算：未設目標價／尚差 NT$ n／已達目標價（該列變底色）
- [ ] 未登入進入追蹤清單時顯示需要登入的鎖定卡
- [ ] 清單為空時顯示空狀態卡；可清空整份清單
- [ ] 不寄送 email，達成目標價僅以畫面狀態呈現（本版範圍外）
- [ ] Web API 層測試涵蓋目標價狀態的判定
